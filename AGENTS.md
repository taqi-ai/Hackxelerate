All coding agents (Claude Code, Gemini CLI, Antigravity, Codex, Cursor) follow the same rules.

- **Gemini and Antigravity:** read [GEMINI.md](GEMINI.md) first and follow it exactly.
- **Claude Code:** read [CLAUDE.md](CLAUDE.md).
- Shared state and handoffs: [docs/HANDOFF.md](docs/HANDOFF.md). Check it before starting work and add one line when you finish.
- Locked: product name (Ascora), stack, scoring logic, existing migrations. Work on a branch and open a pull request; never push to `main` directly.
