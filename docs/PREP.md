# Buildathon prep checklist (Round 2: Oct 24, 16h on-site; Finale: Oct 25)

## Decide before Oct 24
- [ ] Problem statement (one of 4) + one-sentence pitch
- [ ] Core demo flow: the 3 screens / 60 seconds that win the room
- [ ] Roles: product/backend · frontend · AI/integrations · motion + pitch deck
- [ ] Stack locked (see below) and boilerplate pre-scaffolded and deployed once ("hello world in prod")

## Accounts (each teammate, set up at home)
- [ ] GitHub, with the team added to the repo
- [ ] Vercel (web deploy; import the GitHub repo)
- [ ] Supabase or Firebase (auth + DB + storage)
- [ ] LLM API key(s) with credit/free tier verified: Claude / Gemini / OpenAI; keep a backup provider
- [ ] Expo account + Expo Go on phones (only if we ship mobile)

## Machine setup (every laptop)
- [ ] Node 22 LTS, git, VS Code, GitHub CLI (`gh auth login`)
- [ ] `npm i -g vercel` then `vercel login`
- [ ] Clone the repo, `npm install` in each sub-project at home (venue Wi-Fi is unreliable)
- [ ] Remotion: run one render at home so headless Chrome is already downloaded
- [ ] Phone hotspot as backup internet; chargers; extension board

## Deliverables to have ready
- [ ] Deployed URL (+ QR code on the last slide)
- [ ] GitHub repo with a clean README
- [ ] Pitch deck (problem → insight → solution → demo → business model → team)
- [ ] 60–90s Remotion demo video (backup if the live demo breaks)
- [ ] Seed/demo data so the app never looks empty
